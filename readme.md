# Unified Reharmonization

A service to make the Remote from the Logitech Harmony Hub work in Linux.

## Overview

With Logitech Harmony Hub's no longer receiving updates they are becoming less and less useful as new hardware is not supported. However the physical remote is still great and could be useful if could be used in other projects. The cool thing is Logitech used the same hardware as they do for Keyboard/Mice with the unifying receiver for the remote. As such if you have a Logitech Unifying Reciever you can pair the remote to it with the normal Logitech software (or [Web UI](https://logiwebconnect.com/)) and with this software can read the inputs.
